## Setup Instructions
1. Install XAMPP and start Apache and MySQL.
2. Copy the project folder into htdocs.
3. Open phpMyAdmin and create a database named attendance_db.
4. Import database/schema.sql.
5. Edit config/database.php with your database details.
6. Open http://localhost/Web dev_Final Project in your browser.
